User guide & walkthroughOpen workbench

Walkthrough transcript

1. Open and save safely Watch this chapter

Open RAMS Workbench and wait for the analysis engine to load.

Applied changes are saved on this device. An editor stays a draft until you choose Save record. Use Project menu, Back up workspace to keep a recovery copy.

2. Start with the station example Watch this chapter

Choose Project menu, Example studies, Complete station study to create an editable example.

Use Study, Safety, Reliability, Verification, and Review and report to move between tasks. The View selector opens the tools within each area.

3. Explore the Crossrail example Watch this chapter

Choose Project menu, Example studies, Crossrail-informed ventilation study. Open Safety and follow the maintenance-isolation hazard to its current verification obligation.

Inspect the conflicting changeover declarations for the same obligation, mode and configuration.

Open Reports and downloads to inspect the pending receiving condition. Source-linked records open their reference paper and section.

4. Define the study Watch this chapter

Choose Study, then Study definition in the View selector. Record the boundary, configuration, operating context, references and acceptance process.

Add operating modes. For a risk matrix, enter its source and classes, update the grid, assign each category, and save the setup.

5. Model equipment and functions Watch this chapter

Choose Study, then System and functions. Add each equipment instance with a distinct stable ID, and record functions, interfaces and modes.

Inspect equipment to add a child, allocate a function or open its failure analysis worksheet.

6. Follow the hazard board Watch this chapter

Open Safety and choose a hazard. Its assessment, operating mode and boundary stay above the requirement board.

Each row connects a requirement to its controls, verification declarations and next action. Needs review filters missing, incomplete, stale and conflicting coverage.

7. Add a verification declaration Watch this chapter

Define the requirement obligations, then choose Add verification. The editor fills the obligation, mode, configuration and current requirement revision.

Enter a title, artifact details, applicability and reviewer statement. Choose not run for a test plan.

Save the record, inspect the saved scope, then choose Back to board to continue the same hazard review.

8. Record HAZOP examinations Watch this chapter

Choose Safety, then HAZOP worksheet. Create a study node, add an examination, and enter the parameter, guide word and deviation.

Record causes, consequences, safeguards and recommendations. Choose the examination disposition and rationale, then link a hazard or action.

9. Develop failure analysis Watch this chapter

Choose Safety, then FMEA worksheet. Select equipment and add a failure mode.

Record its function, causes, local, next-level and end effects, detection and response. Select a row to edit it, link a hazard or assign follow-up work.

10. Allocate bow-tie controls Watch this chapter

Choose Safety, then Bow tie. Select a hazard and inspect its causes, consequences and controls.

Allocate preventive controls to the incoming paths and mitigative controls to the consequence paths. Select a node to inspect its record, or download the diagram and source JSON.

11. Check and retain a fault-tree result Watch this chapter

Choose Safety, then Fault tree. Build AND and OR gates, reusing the same basic-event ID wherever that event occurs.

Open Analysis setup, set the mode and horizon, and choose whether to quantify independent event probabilities. Check inputs, then Analyze and retain run.

The station example's top-event probability is zero point zero four four. Inspect its cut sets and retained input basis below the diagram.

12. Prepare and calculate RAM Watch this chapter

Open Reliability and choose New RAM study. Define success, mode, mission hours and the repair target, then build the series or active-parallel model.

Resolve the component-input checklist, then choose Check inputs and Calculate and retain run.

Read mission reliability, inherent availability and component repair probability separately.

Open importance and sensitivity to inspect the retained model drivers and one-factor scenarios.

13. Assign and complete actions Watch this chapter

Choose Review and report, then Actions. Filter the register by status, owner or due date.

Use Record completion to add completion evidence or a controlled reference. Follow the linked engineering records when further work is needed.

14. Recover a competing draft Watch this chapter

If another tab saves first, choose Compare latest revision from the blocked draft.

Compare the conflicting fields, choose the values to keep, and save the combined record. Download my draft keeps a separate copy of your edits.

15. Review and freeze a baseline Watch this chapter

Open Review and report to inspect technical findings. Use Trace and change to follow the affected records.

Choose Baselines and history in the View selector. Freeze a named revision, then compare it with the current study.

16. Share the right output Watch this chapter

Choose Review and report, then Reports and downloads. Download study creates a read-only reader; Download archive includes JSON, registers, history, baselines, runs and diagrams.

The receiving-condition schedule keeps the condition, receiving owner, disposition and decision reference together.

Use Project menu, Back up workspace to save all studies and their history before moving devices or clearing site storage.

17. Restore and continue independently Watch this chapter

Choose Project menu, Restore workspace backup. Select the recovery file, inspect the study and record counts, then confirm replacement.

Download previous workspace recovers the preceding workspace. The User guide provides the full procedures and local-app instructions.
