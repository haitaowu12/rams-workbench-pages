Save and recover

Applied changes are saved on this device. An open editor is a draft until you save it. Browser storage belongs to this browser and site address; clearing site data can remove it.

Use Project menu → Back up workspace to retain every study, history entry, baseline and run. Restore workspace backup previews a backup before replacing the browser workspace. The previous saved workspace is retained for recovery through Download previous workspace.

If device saving is unavailable, the app says tab only. Download a backup before closing. When another tab saves, reload the affected project before using its results; stale writes are refused.

The browser workspace limit is 64 MiB. Individual requests retain the 20 MB input limit. Use the local application for larger workspaces.

Share a study

Download study produces a read-only HTML for review. Download full archive includes the project JSON, history, baselines, runs, registers and engineering drawings. Importing project JSON creates a new study; restoring a workspace backup preserves its database identities.

Retained runs identify their exact Python runtime and solver source. A run produced under a different runtime remains historical; it must not silently become a new current result. Recalculate under the current engine when a new result is required.

Method boundaries

RAM covers declared independent exponential components in series or active parallel arrangements. Static AND/OR fault trees preserve shared event identity. Standby, common-cause and shared-repair models, operational availability and dynamic fault trees need other methods. Local declarations do not authenticate approvals or establish engineering acceptance.
